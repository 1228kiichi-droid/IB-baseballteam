# 営業パイプライン

各フォルダに学校ごとのmdファイルを1つ作成して管理する。
ステータスが進んだらファイルを次のフォルダに移動する。

## ステージ
| フォルダ | 意味 |
|----------|------|
| 1_tele-todo | テレアポ未実施 |
| 2_tele-done | テレアポ済み・アポ待ち |
| 3_first-meeting | 初回商談済み |
| 4_proposal | 提案書送付済み |
| 5_negotiating | 契約交渉中 |
| 6_closed-won | 契約締結 → schools/へ移行 |

## 学校ファイルの命名規則
`{都道府県}_{学校名}.md`
例: `東京_〇〇高校.md`
