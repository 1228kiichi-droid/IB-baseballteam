# ジョブズ 行動プロトコル

## 通知チャネル
- **LINE**: 緊急・即時確認が必要なもの
- **Gmail**: 記録に残すもの・資料添付があるもの
- 重要案件は両方に通知する

## アクション分類ルール

### 🔴 実行前に必ず承認を求める（対外アクション）
オーナーに「これをやっていいですか？」と確認し、承認後に実行する。

| アクション例 |
|-------------|
| 顧客・学校への メール送信 |
| 顧客・学校へのLINE・連絡 |
| 契約書・請求書の送付 |
| 外部への提案書送付 |
| SNS投稿（公開コンテンツ） |

**通知フォーマット:**
```
【承認依頼】{アクション内容}
対象: {学校名 / 相手}
内容: {送る内容の要約}
承認する場合: 「OK」と返信
```

---

### 🟢 実行後に報告する（内部アクション）
実行してからオーナーに「やりました、確認してください」と報告する。

| アクション例 |
|-------------|
| 営業パイプラインの更新 |
| 資料・提案書の作成 |
| アイデア出し・戦略立案 |
| SNS投稿の下書き作成 |
| ToDoリスト・カレンダーの更新 |
| 契約校の情報整理・レポート作成 |
| 売上・進捗の集計・分析 |

**通知フォーマット:**
```
【完了報告】{アクション内容}
場所: {ファイルパス or フォルダ}
確認事項: {オーナーに見てほしいポイント}
```

---

## ファイル管理ルール
- 成果物は必ず決められたディレクトリに保存する（ルート直下に置かない）
- 作業中ファイルは `_draft/` サフィックスをつけて管理
- 完成物のみ正式フォルダに移動する
- ファイルを削除する前は必ずオーナーに確認する

## 成果物の置き場所
| 成果物の種類 | 保存先 |
|-------------|--------|
| 提案資料・営業資料 | `marketing/materials/` |
| SNS投稿下書き | `marketing/sns/` |
| 各校レポート | `schools/{学校名}/coaching-log/` |
| 請求書 | `contracts/by-school/{学校名}/` |
| 戦略・アイデア | `ceo/strategy/` |
| オーナーへの報告 | `board/reports/` |
| オーナーへの承認依頼 | `board/inbox/` |
