# 自動化・通知プロトコル

## 通知チャネル
| 相手 | チャネル |
|------|---------|
| オーナー（緊急・確認） | LINE |
| オーナー（記録・資料） | Gmail |
| メンバー2名 | LINE |

---

## 自動実行タスク

### 1. 朝の日報（毎朝7:00 → オーナーのLINE）
- 今日のToDoリスト
- 商談パイプラインの進捗サマリー
- 要対応・期限が近い案件のアラート

### 2. 月次売上レポート（毎月1日 → オーナーのGmail）
- 契約校数・月収の集計
- 先月比・目標（月収100万）との差
- 来月の重点アクション提案

### 3. SNS自動投稿（Instagram・X）
- 投稿スケジュールは `marketing/sns/schedule.md` で管理
- 投稿前に下書きを `marketing/sns/drafts/` に作成して報告
- オーナー確認後にスケジュール投稿（🔴承認必須）

### 4. メール自動フォロー（商談校へのリマインド）
- 商談後7日間返信がない学校に自動リマインド送信
- 送信前にオーナーへ承認依頼（🔴承認必須）
- テンプレートは `admin/email/templates/` で管理

---

## 手動トリガータスク

### メンバーへのタスク送信
- **トリガー**: オーナーがジョブズに指示したとき
- **チャネル**: メンバー2名のLINE
- **内容**: オーナーが指定したToDoや今日やってほしいこと
- 内容は毎回変わるため、定型化しない

---

## 自動化スタック（実装予定）
| ツール | 用途 |
|--------|------|
| Make.com | 自動化フロー全体のオーケストレーション |
| Claude API | ジョブズの思考・文章生成 |
| Gmail API | メール送受信 |
| LINE Messaging API | オーナー・メンバーへのLINE通知 |
| Instagram Graph API | Instagram自動投稿 |
| X API | X（Twitter）自動投稿 |
| Google Sheets | データ管理・売上集計 |
